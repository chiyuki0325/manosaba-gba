# 中文剧本 typo 校对与修正

这是剧本工作流程中的持续环节：发现问题 → 按文本 ID 定位 → 核对上下文 → 同步源文与 JSON → 验证并登记。修正保留原文本 ID、命令和演出时序。

## 处理步骤

1. 根据截图或台词搜索 `original_scripts/zh-Hans/` 和 `story/zh-Hans/`，记录脚本路径、说话人及文本 ID。结合前后台词和对应日文判断，尤其核对“他／她”的指代。
2. 先检查当前文本。已经正确的条目记为“核对通过”，不要仅凭旧版截图再次改文。
3. 确认需要修正时，修改中文 `.nani` 中该 ID 的译文，并同步 JSON 的 `translations[文本 ID]` 和引用该 ID 的 `events[].params`。保留原有标签与换行；不要全局替换“他／她”。
4. 检查源译文、翻译表、事件实际文本三处一致，JSON 可解析，差异仅涉及目标台词。其他活跃工作树若有这份剧本，也同步相同修正，保留各自未提交的工作。
5. 在下表登记，并更新根 README 看板。普通构建会从 JSON 重建 ROM；单纯改字无需重导图像或音乐。涉及排版、选项或控制流时，再运行对应重排／播放器检查。

## 重新提取时的处理

`export_story.py` 从中文 `.nani` 生成 JSON，因此不能只改 JSON。若再次运行 `export_naninovel.py` 从原游戏覆盖 `original_scripts/`，应先按下表重新应用已确认修正，再运行 `export_story.py`；导出后复核这些文本 ID，避免原版 typo 回流。日文源文不改。
