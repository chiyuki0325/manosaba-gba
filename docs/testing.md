# 测试与审计

## 常用入口

需要宿主 C/C++ 编译器、`libmgba-dev` 和 Python 工作区。普通回归使用已准备 ROM；原图编码／导入测试另外需要资产准备环境。

```sh
make -C gba check-list                 # 看本轮改动影响哪些组
make -C gba check TEST_JOBS=12         # 按变化选回归
make -C gba check-full TEST_JOBS=12    # 全量巡检
make -C gba trial-walk-full TRIAL_WALK_JOBS=12
```

Python runner 使用 `python_workspace/.venv/bin/python`。也可显式指定本轮变化，直接运行选定组：

```sh
python_workspace/.venv/bin/python gba/tools/run_regression.py \
  gba/manosaba.gba gba/build-butano/check --changed gba/src/story_vm.cpp --jobs 12
```

全量模式也可传一个 `--changed` 避免查询 Git。`--fresh` 忽略已通过结果缓存。测试工具按源文件及依赖缓存宿主可执行文件，路线从当前 VM 推导；独立模拟器进程共用冻结 ROM。缓存、截图、JSON 和日志均在 `build*/`，不纳入版本控制，不作为构建原料。

230 个 ADV 入口、177 条审判路线及特殊演出测试保留。入口抽查、完整路线、资源像素校验、输入连接和性能预算各自覆盖不同失效点，未因为调用同一底层函数而删掉。

- **常量复述（配方写两颗蛋，再检查写着两颗蛋）**：13站点；删当前语料／布局数量和重复配置字面量。

- **工具／第三方行为（超市的鸡蛋必须有蛋黄）**：3站点；删mGBA左右缓冲数量相等检查，保留实际PCM输出。未采用的分带CG和OBJ kernel探针一并隔离。
- **同分支重复（同尺寸鸡蛋反复炒）**：11站点及native 3场景；每个实际分支仍有见证。
- **跨层重复（厨房验完，收银台再验一遍）**：native 1场景、2次重复宿主runner执行；保留暂停→设置→返回接线。独立普通BG／Trial原型与正式后端重叠的研究测试隔离。

研究矩阵移出常规回归：分带CG为2图×9模式，普通BG独立探针为3图×8品质；OBJ kernel依临时快照决定组合数，不硬报case数。生产普通BG资源往返、出场恢复、画廊、法庭滚动／遮挡及真实音乐负载测试继续保留。通用图块翻转函数已提取为 `tile_orientation.py`，法庭离线渲染保留为 `court_render.py`。
